## 2024-03-05 - Accessibility for Footer Social Links
**Learning:** When adding inline styling `style={{ ... }}` to elements, it often overrides standard utility classes like Tailwind's `hover:text-...`. For elements needing hover or focus states, it's critical to use utility classes consistently (e.g., `text-[var(--color-text-muted)]` and `border-[var(--color-border)]`) rather than mixing inline styles with classes, as inline styles will take precedence and disable the CSS pseudoclasses. Also, when fixing tests around Tailwind classes for string matches on arrays (like `hidden`), make sure to use `split(' ')` first to avoid `toContain` false positives for partial class names like `lg:hidden`.
**Action:** Replace inline base styles with corresponding Tailwind utility classes on interactive elements to ensure hover and focus pseudoclasses function properly without CSS specificity issues. Use string splitting when testing exact class names.
