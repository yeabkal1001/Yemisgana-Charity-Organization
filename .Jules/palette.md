## 2025-02-12 - Keyboard Focus Enhancements
**Learning:** Adding `:focus-visible` styling is essential for keyboard accessibility but often omitted from standard button classes. Applying this via global utility classes (`.btn-primary:focus-visible`, `.btn-ghost:focus-visible`) rather than purely inline Tailwind ensures uniform keyboard accessibility across all component usages, matching the project's existing design tokens (e.g., `--color-lime`). Inline decorative elements inside interactive buttons must also explicitly have `aria-hidden="true"` to prevent redundant screen reader announcements.
**Action:** When auditing custom or generic button utility classes, always verify the presence of explicit `:focus-visible` states. Ensure decorative inner SVG icons within interactive elements have `aria-hidden="true"` set to avoid screen reader clutter.
