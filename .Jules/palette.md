## 2024-05-18 - [Targeting Focus Rings and Aria-Hidden for Accessibility]
**Learning:** When addressing accessibility for a custom Tailwind theme, it's critical to add robust `:focus-visible` styling across global components (e.g. `app/globals.css`) in addition to adding explicit `aria-hidden="true"` to SVGs within button structures, to avoid visual "clipping" and screen-reader noise while preserving the hover semantics with `group`. Also, test string matches (`.toContain`) can falsely fail on responsive prefix classes (`lg:hidden`), so classes should be split into an array before assertions.
**Action:** Always implement `:focus-visible` styling specifically (avoiding raw `:focus`) using CSS variables mapped to the design system. Furthermore, ensure decorative icons explicitly declare `aria-hidden="true"` within interactive elements, and fix unit tests using `.split(' ')` array matches to verify specific classes rather than doing raw string searches.
