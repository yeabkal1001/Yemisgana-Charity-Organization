## 2024-05-30 - Fix Hamburger Menu Desktop Visibility\n**Learning:** When debugging responsive navigation, the hamburger menu button was incorrectly visible on desktop screens (>=1024px) because the `lg:hidden` Tailwind class was missing from its `className` definition, causing it to render alongside the desktop navigation links.\n**Action:** Applied `lg:hidden` class to the hamburger button component so it is hidden on desktop viewports and only visible on mobile/tablet viewports.
