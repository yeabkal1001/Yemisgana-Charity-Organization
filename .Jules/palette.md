## 2024-10-24 - Social Media Icon Accessibility\n**Learning:** When using Lucide React icons directly in an array map for social links, they lack semantic context. Mapping them with explicit labels provides necessary context for screen readers.\n**Action:** When implementing icon-only links, explicitly map the icon component alongside a descriptive label to be used as an `aria-label`, and ensure keyboard users have visual feedback by adding `focus-visible` classes.
