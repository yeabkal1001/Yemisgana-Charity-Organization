## 2026-07-04 - Explicit Labels and Focus Styles for Mapped Icon Arrays
**Learning:** When generating interactive elements (like social media links) by mapping over an array of icon components, the generated links often lack accessible names if `aria-label` isn't explicitly provided. Furthermore, inline styles applied to these mapped components prevent Tailwind CSS pseudo-classes (like `hover:` and `focus-visible:`) from functioning, leading to inaccessible keyboard navigation and poor interactive feedback.
**Action:** Always structure mapping data for icon arrays as objects containing explicit string labels alongside the component (e.g., `[{ Icon: Facebook, label: 'Facebook' }]`). Use these labels for `aria-label` attributes on the surrounding anchor/button. Always replace static inline styles on interactive elements with equivalent Tailwind utility classes to ensure hover and focus states (e.g., `focus-visible:ring-[var(--color-lime)]`) can be correctly applied and override the base styles.
