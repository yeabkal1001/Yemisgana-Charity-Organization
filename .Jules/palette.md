## 2024-05-30 - Keyboard Focus State Enhancements for Buttons and Navigation
**Learning:** Customizing generic classes (like `.btn-primary`, `.btn-ghost`) and generic elements (nav links) to use `focus-visible` ensures that keyboard users receive a strong, high-contrast visual indicator (like `ring-[var(--color-lime)]`), without negatively impacting the visual experience for mouse users (who do not trigger `:focus-visible`). The use of `ring-offset-[var(--color-bg-primary)]` prevents the ring from bleeding incorrectly into the base component background. Additionally, when debugging tests checking for Tailwind classes like `hidden`, string matching (`.toContain('hidden')`) triggers false positives on classes like `lg:hidden`; using array splitting (`classes.split(' ').toContain('hidden')`) is a crucial fix for Vitest.
**Action:** When adding base focus states to shared components in CSS (`globals.css`) or inline via Tailwind, always prefer `:focus-visible` with matching ring and ring-offset properties. Also, when writing Vitest assertions for specific tailwind classes, always split the classList into an array to avoid substring false positives.
