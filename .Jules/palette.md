## 2023-10-27 - Focus States and ARIA hidden on Interactive Elements
**Learning:** Adding robust focus states (`focus-visible:ring-2 focus-visible:ring-[var(--color-lime)] focus-visible:ring-offset-[var(--color-bg-primary)]`) across the entire navigation array greatly enhances keyboard navigation predictability, while keeping the UI clean during mouse interactions. Additionally, applying `aria-hidden="true"` exclusively to decorative inner SVG icons prevents screen readers from redundantly announcing visual elements that are already captured by the parent button's text or `aria-label`.
**Action:** Consistently use the project's existing color variables for focus rings and ensure that SVGs inside labeled buttons have explicit `aria-hidden="true"` applied to keep the accessibility tree concise.
