## 2026-07-03 - Focus Ring Specificity on Styled Icons\n**Learning:** When adding focus-visible styles to icons configured with inline styles for borders and colors, the Tailwind ring utilities (like focus-visible:ring-2) might interact unexpectedly if border and background colors are rigidly set inline. It is crucial to use offset utilities (e.g. `focus-visible:ring-offset-2`) to ensure the focus ring remains distinct from the element's base styles.\n**Action:** Always combine `focus-visible:ring-*` with `focus-visible:ring-offset-*` and `outline-none` when styling interactive elements that use custom backgrounds or borders.
