## 2024-07-10 - Social Icons Accessibility & Interactive States Enhancement
**Learning:** Social media icons at the footer mapped from an array component were missing descriptive `aria-label`s for screen readers. Also, their styling used inline styles (`style={{ background: ..., border: ..., color: ... }}`) instead of Tailwind utility classes. This higher-specificity inline styling broke Tailwind hover and focus states, reducing both visual feedback and keyboard accessibility (missing `focus-visible` ring).
**Action:** Re-mapped social media icons passing explicit string labels and mapping them onto `aria-label` of the interactive `<a>` element, while placing `aria-hidden="true"` on the SVG (`<Icon>`) itself. Extracted all inline styles to equivalent Tailwind classes (`bg-[var(--color-surface)] border border-[var(--color-border)] text-[var(--color-text-muted)]`) and added rich hover (`hover:text-lime hover:border-lime`) and focus states (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[var(--color-lime)] focus-visible:ring-offset-2 focus-visible:ring-offset-[var(--color-bg-primary)]`).
