## 2024-07-20 - Adding Accessibility to Mapped Icon-Only Links
**Learning:** When generating interactive links (like social media icons) by mapping over an array of icon components, accessibility is often missed. The map array needs to be structured as objects containing both the Icon component and a descriptive label string to dynamically set the `aria-label` attribute on the link. Furthermore, explicitly hiding the inner SVG with `aria-hidden='true'` prevents redundant or confusing screen reader announcements.
**Action:** When implementing or refactoring mapped interactive icons, always ensure the data structure provides a clear label for `aria-label` and apply `aria-hidden='true'` to the icon element itself. Also, ensure keyboard accessibility is provided using explicit `focus-visible` utility classes.
